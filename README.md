# Conversor PDF -> XLSX

Aplicação web em TypeScript para:
- anexar PDF;
- delimitar colunas manualmente (guias verticais arrastáveis);
- usar modo "Dados para Colunas" por delimitador;
- visualizar/editar em grade estilo Excel;
- exportar para `.xlsx`.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
